Back End start na pasta que roda o projeto back
.\mvnw.cmd spring-boot:run

Frontend start na pasta que roda o projeto front
node server.js

Evolução do projeto:
1- Autenticação e autorização com spring security + jwt
2- Relacionar post -> usuario -> comentario
3- Paginação para ordenar os posts
4- Ordenação
5- Busca de posts
6- Curtidas
7- Sistema de categorias e tags
8- Tratamento global de exceções
9- Validação
10- Soft delete
11- Auditoria com spring data jpa auditing
12- Documentação com swagger/openAPI
